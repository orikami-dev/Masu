## What's new
- English interface: Masu follows the phone's language (French if the phone is in French, English otherwise). Screens, messages, the log and crash reports are translated.
- Game updates with your own GitHub token: Settings › Game updates. Add a fine-grained token for your private repository to install your games' updates from Masu.
- Extraction: the list of games to extract is easier to spot.
- Game page: shows the game version and the APK version.

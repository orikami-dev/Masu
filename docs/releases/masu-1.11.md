⭐ Major update

## What's new
- Game page: "Install an update or DLC" button; Masu stores the file and re-extracts the game with it.
- Extraction: drop-down list to choose the game, updates and DLC shown under their game with "Install the update".
- Library: game version (update included), game size, and status of unsupported games on the cover.
- Page of an unsupported game: "Report" button for the compatibility page.
- An extracted game without an app opens its page instead of the extraction screen.
- Every download is checked by its SHA-256 fingerprint: a modified file is refused.
- Validated and pinned versions; "Change version" in Settings to go back to a previous Masu version.
- Settings are saved automatically and restored if the file is damaged.

## Fixes
- Update and DLC files no longer appear as games to extract.
- An update whose file name carries no identifier is no longer mistaken for a game.
